# StudyFlow — Student Task and Assignment Management System

## Technologies
Python, HTML, CSS, JavaScript and JSON.

**Flask is NOT used.** The backend uses Python's built-in `http.server`, so there are no external Python packages to install.

## Run in VS Code

1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:
   `python app.py`
5. Open `http://localhost:8000` in your browser.
6. To stop the server, press `Ctrl+C`.

## Features
- Dashboard
- Add, edit and delete tasks
- Subject/category
- Deadline
- Priority
- Pending/completed status
- Overdue count
- Local JSON storage
- Responsive interface
